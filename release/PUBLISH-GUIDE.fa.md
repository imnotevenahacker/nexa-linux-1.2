# راهنمای انتشار جهانی Nexa Linux (نسخهٔ 1.1 پیش‌نمایش)

> **وضعیت:** خروجی ISO هنوز ساخته/بوت/نصب و تأیید نشده. انتشار عمومی نصب‌کننده را پس از تست واقعی انجام بده.

## ۱ — ساخت سایت عمومی (بدون نوشتن کد)

1. وارد [github.com](https://github.com) شو و یک **Public repository** با نام `nexa-linux` بساز؛ اگر GitHub پرسید README بسازه، تیک آن را نزن.
2. پوشهٔ این پروژه را از ZIP خارج کن. راحت‌ترین روش انتقال همهٔ فایل‌ها با **GitHub Desktop** است: File → Add local repository → Create repository here → Commit → Publish repository و Public را انتخاب کن. دقت کن که پوشه‌های مخفی `.github` و فایل‌های دیگر هم منتقل شوند.
3. در GitHub صفحهٔ مخزن را باز کن: **Settings → Pages → Build and deployment → Deploy from a branch → Branch: main → Folder: /docs → Save.**
4. سایت عمومی باید آدرسی شبیه `https://YOURUSERNAME.github.io/nexa-linux/` داشته باشد؛ `YOURUSERNAME` شناسهٔ خودت است. این URL نمونه است و سایت تا وقتی خودت منتشر نکنی وجود ندارد.
5. سایت **انگلیسی و فارسی** است؛ دکمهٔ زبان در بالای صفحه قرار دارد. از سورس کامل پروژه استفاده می‌کند و بدون سرویس پولی مستقل می‌شود میزبانی‌اش کرد.

## ۲ — ساخت ISO قابل نصب

1. در مخزن، **Actions → Build Nexa Linux ISO → Run workflow** را انتخاب کن.
2. برای دستگاه‌های رایج Intel/AMD نسخهٔ `standard` را اول بساز. `ultimate` حجیم است و امکان دارد روی محیط ساخت فضای کافی نداشته باشد.
3. نتیجهٔ build را باز کن. فایل `.iso` و `.sha256` در **Artifacts** قرار می‌گیرند، اما این‌ها انتشار عمومی دائمی نیستند و ممکن است تاریخ انقضا داشته باشند.
4. اگر build شکست خورد یا ISO ساخته نشد، **هیچ فایل ساختگی/تغییرنام‌یافته‌ای به نام ISO منتشر نکن.** Log را بررسی و مشکل را برطرف کن.

## ۳ — چک‌لیست اجباری قبل از ارائه به دیگران

- [ ] ISO واقعاً توسط `live-build` ساخته شده باشد؛ نه ZIP تغییرنام‌یافته.
- [ ] `sha256sum -c filename.iso.sha256` با موفقیت اجرا شده باشد.
- [ ] با QEMU یا VirtualBox در **UEFI** و در صورت ادعای BIOS، در **BIOS** بوت شود.
- [ ] محیط زنده اجرا شود: دسکتاپ، صفحهٔ ورود، Wi-Fi/شبکه، فایل‌ها، Firefox، ترمینال، Okular PDF و Nexa Hub.
- [ ] نصب گرافیکی در یک **دیسک مجازی خالی** بدون خطا کامل شود و اولین بوت سیستم نصب‌شده تست شود.
- [ ] نصب در سناریوی **دیسک مجازی دارای ویندوز** تست شود و همهٔ داده‌های ویندوز باقی بمانند؛ بدون آزمایش، دوال‌بوت را تضمین نکن.
- [ ] اسکریپت‌های GRUB/UEFI، Secure Boot، نصب و مجوزهای نرم‌افزار بررسی شوند.
- [ ] هیچ رمز ثابت، کلید خصوصی، اطلاعات شخصی یا فایل مخرب در ISO و مخزن نباشد.
- [ ] نسخه و مشکلات شناخته‌شده در Release Notes شفاف نوشته شوند.

## ۴ — انتشار دانلود جهانی

1. بعد از موفقیت همهٔ تست‌ها در مخزن GitHub روی **Releases → Draft a new release** کلیک کن.
2. برچسبی مثل `v1.1.0` بزن و عنوان و توضیحات صادقانه بنویس.
3. فایل ISO و SHA256 را در بخش Assets قرار بده و **Publish release** کن.
4. سایت Nexa Linux تازه‌ترین Release را از GitHub می‌خواند و فایل‌های ISO را خودکار نمایش می‌دهد. در صورت نبود Release، سایت به‌درستی می‌گوید هنوز دانلودی آماده نیست.
5. **محدودیت مهم:** حداکثر حجم *هر فایل* در GitHub Releases کمتر از **۲ GiB** است. Ultimate و حتی Standard احتمالاً از این اندازه بزرگ‌تر می‌شوند. اگر بزرگ‌تر بودند، فایل ISO کامل را در یک میزبان مناسب فایل‌های بزرگ مثل SourceForge، یا object storage با پهنای باند کافی منتشر کن و لینک رسمی را در Release Notes قرار بده. هیچ وقت ISO را داخل تاریخچهٔ معمولی Git آپلود نکن (محدودیت فایل‌های Git جداگانه است).
6. برای نام و لوگوی اختصاصی می‌توانی بعداً دامنه بخری. دامنهٔ اختصاصی برای شروع الزامی نیست.

## ۵ — راهنمای Windows 10 + Intel خودت

ویندوز ۱۰ + اینتل ۶۴بیتی عموماً با هدف amd64 این پروژه هماهنگ است، ولی **مدل دقیق CPU، تنظیمات firmware، پشتیبانی درایور و فضای دیسک** تعیین‌کننده‌اند. مشخصات را در Settings → System → About → System type ببین. قبل از دوال‌بوت واقعی از ویندوز بکاپ بگیر، کلید BitLocker/Device Encryption را ذخیره کن، Fast Startup را بررسی کن و **هرگز Erase disk** را برای حفظ ویندوز نزن.

## ۶ — چه چیزهایی هنوز آماده نیست؟

- ISO تست‌شده و واقعاً قابل نصب هنوز وجود ندارد.
- سایت فقط پس از آپلود مخزن عمومی آنلاین می‌شود.
- پشتیبانی جهانی شامل گوشی‌ها، آیپدها، کنسول‌ها، Mac Apple Silicon و همهٔ مدل‌ها نیست؛ هر معماری نیاز به پورت و بررسی جدا دارد.
- بازاریابی با ادعای «نصب تضمینی روی همهٔ دستگاه‌ها» قبل از تأیید خطرناک و گمراه‌کننده است.
