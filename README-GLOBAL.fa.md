# NEXA LINUX GLOBAL KIT — نسخهٔ انتشار عمومی 1.1

> شامل پروژهٔ واقعی ساخت Nexa Linux 1.0 و قالب سایت فارسی/انگلیسی. **ISO نهایی هنوز ساخته/تست نشده و در این ZIP موجود نیست.**

## آمادهٔ چه چیزی است؟

- سایت عمومی در پوشهٔ `docs/` با تغییر زبان فارسی/انگلیسی، طراحی واکنش‌گرا، امکانات، نسخه‌ها، راهنمای نصب و دانلود متصل به **Release واقعی GitHub**.
- لوگوی اختصاصی SVG سایت، بدون استفاده از برند Microsoft.
- پروژهٔ ساخت ISO بر پایهٔ Debian 13 + KDE Plasma 6 و سه edition: Lite / Standard / Ultimate.
- ساخت ISO در GitHub Actions (در صورت موفقیت) و گزارش SHA256.
- راهنمای قدم‌به‌قدم انتشار عمومی و چک‌لیست تست بوت، نصب و دوال‌بوت.

## انتشار جهانی در ۵ قدم

1. یک مخزن **Public** در GitHub بساز با نام `nexa-linux`.
2. محتویات این پوشه (از جمله `.github`) را با GitHub Desktop در مخزن منتشر کن.
3. Settings → Pages → Deploy from a branch → `main` → `/docs` → Save.
4. در Actions → Build Nexa Linux ISO نسخهٔ `standard` را بساز. اگر ساخت ناموفق بود، خطا را اصلاح کن. فایل ISO واقعی را اول روی VM، نصب‌کننده و پارتیشن‌بندی تست کن.
5. در Releases یک انتشار عمومی بساز و فقط ISO تست‌شده + SHA256 را قرار بده. سایت خودکار Latest Release را نمایش می‌دهد.

**توجه: هر فایل GitHub Release باید زیر ۲ GiB باشد؛ برای ISO بزرگ‌تر میزبان دیگری نیاز است.**

راهنمای دقیق: `release/PUBLISH-GUIDE.fa.md`.

## دربارهٔ Windows 10 و پردازنده Intel

برای کامپیوترهای **Intel/AMD 64-bit** هدف build معماری `amd64` است؛ نام `amd64` به معنی انحصار به پردازندهٔ AMD نیست. در Settings → System → About → System type ویندوز ببین `64-bit` نوشته شده یا نه. فعلاً Nexa را فقط در ماشین مجازی آزمایش کن؛ دوال‌بوت روی هارد اصلی تا قبل از تست کامل توصیه نمی‌شود.

## وضعیت واقع‌بینانه

«انتشار در سایت» با «ساخت سیستم‌عامل قابل نصب و پایدار» متفاوت است. فایل ZIP حاضر **کد سایت و سیستم ساخت** است؛ چیزی را به‌جای ISO قابل نصب جا نمی‌زند. نشر عمومی و حساب GitHub هم نیازمند اقدام صاحب حساب است.
