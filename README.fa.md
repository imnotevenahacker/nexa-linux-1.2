# ✦ Nexa Linux 1.0 — بستهٔ ساخت سیستم‌عامل واقعی

**وضعیت: پروژهٔ آمادهٔ ساخت ISO، نه ISO نهاییِ ساخته‌شده یا تست‌شده.** این مخزن یک سیستم‌عامل جدید از صفر (کرنل تازه) نیست؛ یک توزیع سفارشی واقعی بر پایهٔ Debian 13، KDE Plasma 6، برنامه‌های آزاد و نصب‌کنندهٔ Calamares است. امکان استفاده از ابزارهای استاندارد لینوکس، مدیریت بسته‌ها و دسترسی به هزاران برنامهٔ مخازن وجود دارد، ولی هزاران برنامه به‌صورت پیش‌فرض نصب نشده‌اند.

## امکاناتی که در ساخت پیش‌بینی شده

- **رابط شبیه ویندوز ۱۱:** پنل پایین با منوی برنامه‌ها، وظایف و ساعت؛ تم روشن/تاریک؛ تصویر پس‌زمینهٔ ویژهٔ Nexa؛ صفحهٔ ورود SDDM و مرکز کنترل اختصاصی.
- **Nexa Hub:** برنامهٔ Qt 6 واقعی برای اجرا کردن ابزارهای نصب‌شده، انتخاب والپیپر، تغییر تم، جست‌وجوی برنامه‌ها و آپدیت؛ همراه با شناسایی خودکار برنامه‌های در دسترس.
- **وب و شبکه:** Firefox ESR مرورگر کامل، مدیریت وای‌فای، بلوتوث، مدیر دانلود، Thunderbird ایمیل، ریموت‌دسکتاپ و ابزار شبکه (بسته به نسخه).
- **فایل و اسناد:** Dolphin، Okular برای PDF، LibreOffice، آرشیو ZIP/7z با Ark، عکس با Gwenview و ابزار جست‌وجو (بسته به نسخه).
- **سرگرمی:** KMines، KPat و KSudoku؛ در نسخه‌های بالاتر KBreakOut، KMahjongg، SuperTux و SuperTuxKart.
- **رسانه/خلاقیت:** VLC، MPV، Krita، GIMP، Inkscape و در Ultimate برنامه‌های تدوین، صدا، سه‌بعدی و ضبط صفحه.
- **فناوری:** Konsole و ابزار واقعی Linux، Git، و در Ultimate ابزارهای توسعه، Node.js، ساخت نرم‌افزار و ماشین مجازی.
- **شخصی‌سازی:** تغییر کامل از KDE System Settings (پنل، ویجت، تم، فونت، میانبرها، چند دسکتاپ مجازی).
- **کاربری و امنیت:** رمز ورود و قفل صفحه، SDDM، به‌روزرسانی‌های Debian، UFW و KeepassXC (در صورت نصب). پسورد در فرایند نصب توسط کاربر انتخاب می‌شود و در پروژه پسورد ثابتی وجود ندارد.
- **بوت و نصب:** ISO هیبرید برای x86-64 با پشتیبانی مورد نظر برای UEFI و BIOS و نصب‌کنندهٔ Calamares برای نصب روی دیسک.

## نسخه‌ها

| Edition | هدف | محتوا |
| --- | --- | --- |
| `lite` | کم‌حجم‌تر | دسکتاپ، وب، PDF، ترمینال، ماشین حساب، فایل، شبکه، چند بازی |
| `standard` | کارهای روزانه و بازی سبک | Lite + آفیس، برنامه‌های مدیا/طراحی، بازی‌های بیشتر |
| `ultimate` | امکانات بسیار بیشتر | Standard + OBS، Kdenlive، Blender، توسعه و ابزارهای پیشرفته |

**حجم ISO هنوز معلوم نیست** و فقط پس از ساخت مشخص می‌شود. اجرای Ultimate به منابع و فضای زیادی نیاز دارد و انتظار نیست به‌اندازهٔ Lite سبک باشد. هیچ‌یک روی سخت‌افزار واقعی تأیید نشده‌اند.

## دانلود فقط با چند کلیک (بعد از گذاشتن پروژه در GitHub)

پروژه شامل فایل workflow ساخت خودکار ISO است. برای اجرا باید ZIP مخزن در یک Repository گیت‌هاب خودت آپلود شود و Actions مجاز باشد. سپس:

1. GitHub > **Actions** > **Build Nexa Linux ISO**.
2. **Run workflow** > نسخهٔ `standard` را انتخاب کن > Run.
3. فقط **اگر Build موفق شد**، آخر همان صفحه روی Artifacts بزن و ZIP شامل `.iso` و `.sha256` را دانلود کن.
4. با Rufus یا BalenaEtcher فایل ISO را روی فلش بنویس (فلش پاک می‌شود).

محدودیت: برای دریافت ISO باید یک بار GitHub Workflow اجرا شود؛ اینجا فایل ISO چندگیگابایتی ساخته نشده و لینک دانلود ISO موجود نیست. ساخت در GitHub Actions هم *تضمینی نیست*؛ خطاهای احتمالی بسته‌ها و بسته‌بندی باید بررسی شوند.

## ساخت در Debian 13

در محیط Linux amd64 با دسترسی به اینترنت و فضای آزاد کافی:

```bash
sudo apt update
sudo apt install -y live-build debootstrap squashfs-tools xorriso grub-pc-bin grub-efi-amd64-bin dosfstools mtools syslinux-common isolinux
sudo ./build.sh standard
# lite یا ultimate نیز قابل انتخاب است.
```

ISO و فایل SHA256 پس از موفقیت ساخت در پوشهٔ پروژه ظاهر می‌شوند. از `scripts/check-packages.sh` پس از apt update برای بررسی نام بسته‌ها استفاده کن. قبل از بیلد مجدد `sudo ./clean.sh` بزن. برای آزمایش ساختار فایل `.iso` ابزار `scripts/check-iso.sh` وجود دارد؛ این ابزار **تست بوت نیست**.

## قبل از نصب کنار Windows 11 — خیلی مهم

**تست‌نشده و بالقوه خطرناک:** حتی اگر ISO ساخته شود، تا قبل از آزمایش در ماشین مجازی و بررسی مدل لپ‌تاپ/PC مناسب نصب روی دیسک واقعی نیست. از روی نصب‌کنندهٔ گرافیکی می‌توان *در صورت وجود شرایط* پارتیشن‌های جداگانه ساخت، اما عملکرد دوال‌بوت این توزیع فعلاً تضمین نشده است.

1. از اطلاعات خود بکاپ مستقل بگیر و *کلید بازیابی BitLocker* را بیرون از کامپیوتر ذخیره کن. وضعیت Device Encryption را هم بررسی کن.
2. پارتیشن ویندوز را فقط با ابزار مناسب ویندوز کوچک کن و فضای **Unallocated** ایجاد کن؛ پارتیشن EFI و Recovery را حذف نکن.
3. Fast Startup ویندوز را برای جلوگیری از مشکلات mount سیستم‌فایل خاموش کن؛ Secure Boot را فقط با آگاهی از پیامدها تغییر بده.
4. فایل ISO را در ماشین مجازی با بوت UEFI تست کن؛ سپس روی USB بزن و وارد محیط Live شو.
5. با برنامهٔ **Install Nexa Linux** (Calamares) از Nexa Hub یا منوی برنامه‌ها جلو برو؛ گزینه‌های Partition را با دقت بخوان. **Erase disk/Replace partition ممکن است ویندوز و فایل‌ها را پاک کند.** فقط طرح پارتیشن‌بندی را تأیید کن که دقیقاً خواسته‌ات را نشان دهد.
6. زمان نصب نام کاربر و **رمز ورود قوی** را انتخاب کن. به نسخهٔ Live برای حفاظت از اطلاعات محرمانه تکیه نکن.
7. پس از نصب وجود گزینه‌های بوت Windows Boot Manager و Linux را بررسی کن؛ `os-prober` همیشه به‌طور پیش‌فرض فعال نیست و ممکن است GRUB ویندوز را خودکار نشان ندهد.

## پشتیبانی سخت‌افزاری

هدف این نسخه **کامپیوترهای معمولی x86-64** است. برای Android/iPhone/iPad و حتی برخی لپ‌تاپ‌های ARM صرفاً همین ISO کافی نیست. پشتیبانی GPU، وای‌فای، Secure Boot و بعضی سخت‌افزارها وابسته به کرنل، فریم‌ور و دستگاه است. هیچ تضمینی برای «تمام دستگاه‌ها» وجود ندارد.

## نکات فنی

- Debian GNU/Linux 13 (trixie) حفظ شده تا APT و Calamares/بسته‌ها ناسازگار نشوند؛ برند Nexa در مرکز کنترل، launcherها، آیکون و والپیپر اعمال می‌شود.
- پروژهٔ MIT برای کدهای Nexa است؛ سایر بسته‌های Debian/KDE/برنامه‌ها مجوز جدا دارند. Nexa ارتباط رسمی با Debian، KDE و Microsoft ندارد.
- چیدمان پنل در اولین ورود به‌صورت *best effort* اعمال می‌شود و امکان تفاوت با نسخه‌های Plasma وجود دارد.
- این پروژه **از نظر سینتکس اسکریپت‌های محلی بررسی شده** ولی **بیلد کامل، بوت ISO، نصب Calamares، Secure Boot و دوال‌بوت آن تست نشده است**؛ این موارد باید قبل از هر انتشار عمومی صحت‌سنجی شوند.
