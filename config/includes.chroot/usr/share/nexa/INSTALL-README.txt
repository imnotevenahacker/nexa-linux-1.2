Nexa Linux 1.0 development build
================================
This is an unofficial Debian 13 KDE derivative, NOT a verified OS release.
- Use the graphical Install Nexa Linux shortcut in a live boot.
- Choose a strong password in the installer.
- For Windows dual-boot, back up first. Never choose erase disk.
- Secure Boot and dual-boot detection depend on the target machine.
- Test UEFI boot and installer in a VM before installing to real storage.
