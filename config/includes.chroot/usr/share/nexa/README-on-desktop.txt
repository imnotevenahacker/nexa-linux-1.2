Nexa Linux 1.0 — Unofficial Debian KDE derivative

Live desktop: Launch Install Nexa Linux (Calamares) to install on a disk.
Do not choose erase disk when keeping Windows. Back up files and BitLocker recovery key first.
Not verified for dual-boot. Do not install untested builds to a production machine.
Use Nexa Hub to change appearance and launch programs.
No built-in password; select account and password during installation.
