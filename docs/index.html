Installation — important

These steps apply only after a tested installer ISO is released. Dual boot always carries risk.

Back up first

Save important Windows files and your BitLocker recovery key if enabled.

Test before installing

Verify the ISO checksum; test the image in a virtual machine before writing it to USB.

Protect Windows

Create unallocated disk space. Never select Erase disk if keeping Windows.
